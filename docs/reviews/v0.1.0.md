# Independent review for v0.1.0

Step 4b of the release procedure: the requirements in this release were
re-checked by a reviewer that did not write them.

- **Reviewer:** a separate AI agent (Claude Sonnet) in a fresh context. It was
  told not to trust the author's summaries, commit messages or
  docs/planted-faults.md, and to derive each verdict from the code and tests.
- **Date:** 2026-11-14, on branch `release/v0.1.0` at main `aa79601` plus
  uncommitted verification-artifact edits.
- **Status:** advisory. At v0.x a missing or dissenting review is recorded,
  not blocking.

## Accepted as partial for v0.1.0, tracked as issues

- The timeline sorts by camera wall-clock time and ignores the stored offset.
- EXIF date fallbacks, GPS sign handling, 0,0 rejection and GPSStatus have no
  dedicated test.
- No test for EXIF orientation in thumbnails or for the cache cap itself.
- The index schema-version check and the scan exit code 2 are not exercised
  by a test (no test runs the binary).
- The scan's nice check is vacuous when the test process already runs at nice
  19; the planted-fault run for it (F11) runs at nice 0, and CI runs at nice 0.
- I/O priority is set only on Linux and is not tested.
